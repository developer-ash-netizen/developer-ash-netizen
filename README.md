What if the user retries?
What if the payment succeeds but the callback fails?
What if the database transaction fails?

What if the user loses connection?

What if the system scales?
What if someone abuses the endpoint?

Demo

and

Production System

And don't forget the Snake workflow

Create:

.github/
└── workflows/
    └── snake.yml

name: Generate Contribution Snake

on:
  schedule:
    - cron: "0 0 * * *"

  workflow_dispatch:

jobs:
  generate:
    runs-on: ubuntu-latest

    steps:
      - name: Generate Snake
        uses: Platane/snk@v3
        with:
          github_user_name: sreehaasan
          outputs: |
            dist/github-contribution-grid-snake.svg

      - name: Publish Snake
        uses: crazy-max/ghaction-github-pages@v4
        with:
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          BUILD_DIR: dist
