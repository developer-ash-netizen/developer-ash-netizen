Featured Projects
1. CivicLens — Civic Issue Reporter
Stack: React, TypeScript, Vite, Tailwind CSS, Node.js, Express, MongoDB, Leaflet

A civic-reporting web application prototype for issues such as potholes, garbage, broken streetlights, and water leaks.
- Lets users submit a photo and location for a civic issue.
- Uses AI vision to suggest a category and severity, with a manual fallback.
- Displays reports on a map and supports duplicate-prevention checks.
- Includes an admin workflow for tracking reports from Reported to In Progress to Resolved.
2. Dhruthaa — Local-Shop Commerce Platform
Stack: React, TypeScript, Vite, Node.js, Express, MongoDB

A local-commerce platform being developed around local shops and quick delivery.
- Planned panels for customers, merchants, delivery partners, and administrators.
- Backend work covers commerce flows such as orders, delivery, authentication, wallet/ledger logic, and COD settlement.
- Development is being approached in stages, with a COD-first local pilot planned.
3. StudyShare — Educational Resource Platform
Stack: React, TypeScript, Tailwind CSS, Node.js, Express, MongoDB

A study-material sharing platform focused on helping students find and organize learning resources.
- Organizes notes and PDFs by subject and category.
- Focuses on searching, sharing, and a straightforward student experience.
- Planned storage integration uses Google Drive for study files.
4. AI-Powered Personal Health Copilot
Focus: OCR, information extraction, AI summarization, health-record organization

A prototype explored as part of an Altrix Labs challenge.
- Extracts information such as medicines, dosages, test values, diagnoses, and dates from medical records using OCR.
- Generates plain-language AI summaries and organizes records into a timeline.
- Explores multilingual summaries and an interoperable, FHIR-style data structure; this is a prototype, not a clinical diagnostic tool.
5. GeoSR-X v4 — Satellite Image Super-Resolution
Team: AntarNetra · Smart India Hackathon 2026 · Problem statement: SIH26142

A project focused on super-resolution for medium-resolution Sentinel-2 satellite imagery.
- Contributed to the solution architecture and a working frontend/backend prototype.
- Explores evidence-aware processing, provenance, confidence estimation, and validation.
- Intended for geospatial use cases such as agriculture, urban analysis, disaster response, and environmental monitoring.
6. ML Smart Scan Strategy — Electronic Warfare Scheduling
Focus: Machine learning, adaptive scheduling, simulation, evaluation · Smart India Hackathon 2026

A research-oriented project exploring an adaptive scan scheduler for an electronic-support receiver when emitter details are not known in advance.
- Planned pipeline includes an RF simulator, a conventional scanning baseline, and an adaptive probability-based scheduler.
- Evaluation targets include detection probability, false-alarm rate, and intercept time.

Contribution Snake Setup
Create these files and folders:
.github/
└── workflows/
    └── snake.yml
Create .github/workflows/snake.yml with:
name: Generate Contribution Snake

on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch:

jobs:
  generate:
    runs-on: ubuntu-latest

    steps:
      - name: Generate Snake
        uses: Platane/snk@v3
        with:
          github_user_name: sreehaasan
          outputs: |
            dist/github-contribution-grid-snake.svg

      - name: Publish Snake
        uses: crazy-max/ghaction-github-pages@v4
        with:
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          BUILD_DIR: dist
